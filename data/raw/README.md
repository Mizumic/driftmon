# data/raw/ · 原始观测层（append-only）

**这里是唯一不可再生的数据。**

## 规则

* **只追加，不修改，不删除。** 过期靠滚动分卷（按天一个文件），不靠改写历史。
* 每条记录必须带 `probeSetHash`——没有它，这条样本永远无法参与比较。
* 每条样本必须带 `provenance`（`endpointId` / 上游串 / 响应 id 形态 / trace id / 机房）——
  否则无法把"路由漂移"从"模型漂移"里拆出来。**这是本项目最容易产生假阳性的地方**。
* **不许**写入：prompt 原文、响应正文、任何凭据字段（授权头必须已被脱敏）。
* **冒烟批次必须标 `partial: true`**（只跑了部分组，例如 `--only T`）：它照样落盘、可复盘，
  但**不参与**基线与判定（`signature.isComparableBatch` / `judge` 都会跳过）。

## 体积预期（据实测）

| 项 | 量级 |
| --- | --- |
| 单次探针组 | ≈ 1.8k token 的用量数字 + 少量概率数组 + 失败位图 |
| 单条样本落盘 | 约 1–3 KB |
| 按 6 小时跑一批（K=8 个会话） | 约 10–25 KB/批 |
| 一年 | **约 15–35 MB** |

对照：插件的 `raw/` 目录（完整 SSE 响应字节）稳态是 10–15 MB——**本项目存的是摘要，不是正文**，所以更轻。
