# data/baselines/ · 基线层

**滚动窗口的分布统计。可整体重建，但重建必须留原因。**

## 规则

* 一个基线**只对一个 `(端点, 通道)`**负责；不同端点的样本**绝不混池**（混池会掩盖路由漂移）。
* 每个基线绑定一个 `probeSetHash`；探针组变了，旧基线不删除但标记 `stale`，新基线另存版本号。
* 基线里必须包含 `noiseFloor`（来自 Phase 0 的噪声标定）——它是所有阈值判定的分母。

## 计划中的文件

| 文件 | 内容 |
| --- | --- |
| `noise-floor.json` | **Phase 0 产物**：各通道在稳定态的自然波动（p50 / p95 / p99、唯一值计数） |
| `current.json` | 当前生效的滚动基线（带 `baselineVersion`） |
| `history/` | 历史基线归档（只读，用于回溯与画时间线） |

## 危险操作

重建基线会**改变判定的基准**。任何重建都要在 `history/` 留一份旧版，并在报告里写明：
为什么重建、重建前后同一批样本的判定是否发生变化——**如果变化了，说明之前的结论不可靠，要如实记录。**
